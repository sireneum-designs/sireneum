SHARED FIXTURES

'shared' means symbols appear on both sheets.

Move one on A-101 and it moves on A-102 too. Switches, receptacles and wall devices default to one sheet only.  Lighting is shown on both the Electrical Plan and the Reflected Ceiling Plan

03 · MAKING CHANGES

Choose the fixture type

Select a light, then pick its Type mark (A, B, C…) in the Selection panel on the right.

The Schedules below it list what each type is, such as A for LED track lighting or B for 4 in. wafer downlights, and how many are on the plan.

New lights you drop take the last type you chose for that symbol.

04 · QUESTIONS AND COMMENTS

Not sure? Leave a comment flag

When you're unsure, a flag is better than an edit.

1

Click Comment flag, or press C

2

Click the spot on the plan

3

Type your comment. The first time, it asks for your name

We reply in the same thread and close the flag once it's resolved. The Comments panel lists open flags for each sheet.

04 · WORKING TOGETHER

Four habits that keep us in sync

Start fresh each time

Use Refresh to be sure you're looking at the latest version. Close the tab at the end of each editing session. 

One tab at a time

Keep the plan open in just one browser tab.

Flag all changes

Before moving or deleting something we placed, leave a flag saying why.

Live updates, for synchronous meetings

Working at the same time? Turn on Live updates under Display. It turns off after 10 quiet minutes.

05 · PRINTING

Print or save a PDF

Print / Export… makes a to-scale PDF with the title block, notes and schedules.

Pick the sheet size and scale, then Download PDF.

To print at true scale, set your print dialog to 100% or Actual size on the matching sheet.
